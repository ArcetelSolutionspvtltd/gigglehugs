# **App Name**: GiggleHugs Babysitting

## Core Features:

- Home Page Hero: A cheerful hero section with clear calls to action.
- Babysitter Profiles: Display sitter profiles including name, photo, bio, certifications, and age groups.
- Babysitter Database: Enable admins to add, edit, or remove sitters through a simple dashboard, which stores to Supabase.
- Services Page: Show babysitting services and optional add-ons.
- Testimonials Section: Display parent reviews to build trust.
- Content Management: Allow admins to edit page content using a WYSIWYG editor, stored in Supabase.
- AI Sitters Tool: Generate an original bio for a new babysitter with an AI tool, reasoning about experience and certification details.

## Style Guidelines:

- Primary color: Soft Yellow (#FFD700) to evoke sunshine and joy.
- Background color: Very pale yellow (#FAF9F0) for a warm, welcoming base.
- Accent color: Light Orange (#FFA07A) for a friendly and approachable vibe.
- Body and headline font: 'PT Sans', a humanist sans-serif, will give the text a modern yet warm feel.
- Use playful icons representing love, sunshine, and giggles.
- A clean, friendly, and approachable layout that instills trust.
- Subtle, heartwarming animations on hover and page transitions to enhance the joyful feel.
