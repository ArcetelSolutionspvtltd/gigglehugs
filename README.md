# 🌟 GiggleHugs — Babysitting Services Platform

GiggleHugs is a modern, faith-centered babysitting service platform built with **Next.js**, **Supabase**, and **TypeScript**.  
It provides a secure admin dashboard to manage services, sitters, testimonials, contact information, and social links.

---

## 🚀 Tech Stack

- **Next.js 14 (App Router)**
- **React**
- **Supabase** (Auth + Database + Storage)
- **Tailwind CSS**
- **React Icons**
- **TypeScript**

---

## 🛠 Features

- **Admin Dashboard** to manage:
  - Services
  - Sitters
  - Testimonials
  - Contact details (phones & emails)
  - Social links (WhatsApp, Instagram, Facebook, TikTok etc.)
- **Supabase Authentication**
- **Supabase Storage Uploads** for sitter & testimonial avatars
- **Dynamic Icon Selection**
- **Responsive UI** built with Tailwind CSS
